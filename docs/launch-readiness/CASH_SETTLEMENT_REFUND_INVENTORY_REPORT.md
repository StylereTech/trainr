Provider references rechecked 2026-10-14: Stripe documents that [event order is not guaranteed](https://docs.stripe.com/webhooks#event-ordering), and its [Refund object](https://docs.stripe.com/api/refunds/object) distinguishes pending, requires-action, succeeded, failed and canceled states. Reading current refund inventory before fulfillment is the engineering response tested here, not evidence that any hosted Stripe transaction succeeded.
